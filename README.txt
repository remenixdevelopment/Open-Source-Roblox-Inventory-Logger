To start
--------------------------------------------------------------------
open up your user.txt file 
paste in your list of user id's
press the file button in the top left and press save and back out 


To run it
--------------------------------------------------------------------
there will be 2 commands you can run 

python scanner.py only scans for collectables/limiteds/rap 
 
python scanner2.py scans for literally everything 

copy either or and paste it into the cmd prompt 

--------------------------------------------------------------------
To check results 
--------------------------------------------------------------------
go back to the main folder and there should be a .txt file that says results if you use scanner.py 

if you use scanner2.py you will see 2 result sections 1 .txt one that will open your browser and have the items in order and with direct links to them
