# Open-Source-Roblox-Inventory-Logger
Logs roblox account inventories that are public 


Totally open source Roblox inventory logger only thing you really need for it is python

The typical use for this is to mass check roblox id's and log there public inventory items to keep track of which accounts are in possession of what items especially offsale items
